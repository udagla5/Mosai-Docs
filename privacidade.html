Política de Privacidade

Última atualização: 31 de agosto de 2026

1. Introdução

A sua privacidade é prioridade para nós. Esta Política de Privacidade explica como o aplicativo Mosai coleta, utiliza e protege as suas informações, especialmente no que diz respeito à integração com os serviços do Google.

2. Acesso e Uso de Dados do Google (Google Workspace APIs)

O aplicativo Mosai solicita acesso ao seu Google Drive exclusivamente para ler os arquivos que você selecionar ativamente. O uso das informações recebidas das APIs do Google está sujeito à Política de Dados de Usuários dos Serviços de API do Google, incluindo os rígidos requisitos de Uso Limitado.

  • O que acessamos: O aplicativo só possui acesso de leitura aos arquivos específicos (planilhas de dados e fotos) que você escolhe abrir utilizando o seletor nativo do Google Drive integrado ao app.
  • Como usamos: Os dados (nomes, métricas, assiduidade e fotos) são processados para gerar relatórios, exportações em PDF e painéis pedagógicos dentro da interface do aplicativo.
  • Processamento Local (On-Device): Nós não enviamos seus arquivos do Google Drive, dados de planilhas ou fotos para servidores externos. Todo o processamento e cruzamento de dados ocorre de forma nativa e isolada no seu próprio dispositivo (iPhone/iPad). Nós não vendemos, transferimos ou compartilhamos os dados escolares com terceiros.

3. Armazenamento de Dados

As informações extraídas das planilhas são armazenadas localmente no banco de dados interno do seu dispositivo. Você mantém controle total sobre esses dados e pode excluí-los permanentemente a qualquer momento apagando o conjunto de dados no próprio aplicativo ou desinstalando-o.
